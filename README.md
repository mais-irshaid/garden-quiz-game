# رحلة في بستان الأنظمة

لعبة تعليمية تفاعلية لمادة **المهارات الرقمية** للصف السابع الأساسي، تراجع درس **نظام التشغيل** (كتاب المهارات الرقمية، الصفحات 40 إلى 46).

**رابط اللعبة:** https://mais-irshaid.github.io/garden-quiz-game/

## فكرة اللعبة

تمشي فتاة في حديقة جميلة، فتعترض طريقَها عشر صخور. كل صخرة تُخفي سؤالًا من ثلاثة خيارات:

- عند الإجابة الصحيحة تختفي الصخرة، وتتحوّل إلى وردة تطير إلى سلّة الورد، ثم تتابع الفتاة سيرها.
- لكل لعبة **ثلاث محاولات فقط**، وتُحتسب على الأسئلة العشرة كلها، ولا تتجدّد عند الانتقال إلى سؤال جديد.
- إذا استُنفدت المحاولات الثلاث تتوقف اللعبة وتبدأ من جديد.
- إذا اجتازت الفتاة الصخور العشر تظهر رسالة الفوز «تهانينا! لقد فزتِ!».

## المزايا

- بنك من **50 سؤالًا**، وتختار اللعبة **10 أسئلة عشوائية** في كل مرة، مع خلط ترتيب الخيارات.
- محاولة عدم تكرار الأسئلة نفسها في الألعاب المتتالية.
- أصوات بسيطة للبدء والإجابة الصحيحة والخاطئة والفوز والخسارة، مع زر لكتم الصوت.
- تتسع الصفحة في شاشة الحاسوب واللوح الذكي دون شريط تمرير، وتعمل على الهاتف.
- لغة عربية فصحى في الأسئلة والواجهة.

## بنية المشروع

| الملف | الوصف |
| --- | --- |
| `index.html` | هيكل الصفحة |
| `style.css` | التنسيق والحركات |
| `script.js` | منطق اللعبة |
| `questions.js` | بنك الأسئلة (يمكن تعديله بسهولة) |
| `assets/girl.png` | صورة الشخصية |

اللعبة مكتوبة بـ HTML وCSS وJavaScript فقط، بلا مكتبات ولا خادم.

## التشغيل على الحاسوب

نزّل الملفات في مجلد واحد، ثم افتح الملف `index.html` بأي متصفح، ولا حاجة إلى الاتصال بالإنترنت (باستثناء الخط العربي، وله خط بديل).

## تعديل الأسئلة

افتح الملف `questions.js` وأضف سؤالًا بالصيغة الآتية:

```js
{ text: "نص السؤال؟", options: ["الخيار الأول", "الخيار الثاني", "الخيار الثالث"], correctIndex: 1 },
```

حيث يدل `correctIndex` على رقم الإجابة الصحيحة: `0` للأول، و`1` للثاني، و`2` للثالث.
